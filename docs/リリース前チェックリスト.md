- [ ] 伝統7天体のサイン品位が、支配`+0.80`・高揚`+0.55`・損傷`-0.55`・フォール`-0.75`として、実際のアスペクト・リターン・有効ハウス通過時だけ反映される。同一天体の二重加算はなく、分野ごとの合計は`-1.4〜+1.4`点。外惑星・ASC・MCへ流派依存の固定品位点を付けていない。本格の「この点数の理由」と毎日・週・月・年JSONの`planetary_sign_dignity_effects`に、対象天体・星座・状態・式が表示される。
- [ ] アプリコードで使っていない通信系依存が残っておらず、Profile・Release版のAndroid Manifestにインターネット権限が入っていない。
- [ ] 健康・メンタル運が65点以下の毎日・週・月・年は、通常の本文内で「体調・メンタルを気にかける日／期間」と短く表示する。占い点数を病気のなりやすさ・受診の必要性に結び付けず、病名の予測をしない。
