# リリース前チェックリスト

## 表示・占い

- [ ] 正式名が「ぱんちょ式 超本格占星術占い」、短縮名が「ぱんちょ式星占い」と表示される。
- [ ] 毎日占いの上部に、JST時刻付きの星イベントと、深夜・朝・日中・夜それぞれの星配置を反映した短い案内が表示される。月相は毎日、8段階の位相・照度・月齢目安を表示し、新月／上弦／満月／下弦の当日は分単位のJST時刻とともに表示される。逆行・留・空のステリウム・グランドトラインは、該当日にだけ短い説明とともに表示される。
- [ ] 留（逆行開始・終了）がある日の簡易・本格総合運には、該当天体のテーマと切替直後の行動判断が入る。水星以外の金星〜冥王星も対象にする。
- [ ] 月ボイドと留が同日に重なっても、簡易・本格総合運の両方へ留の判断が残る。新月・満月、太陽・水星・金星・火星の星座移動、空のステリウムも該当日には総合運本文へ反映される。
- [ ] 星座名に「射手座座」などの重複表記がなく、週占いの運勢グラフ下部には曜日と月/日が併記される。
- [ ] 毎日占いの総合運要約は、80点以上の運勢をすべて「好調」、65点以下をすべて「注意」と表示し、該当なしの場合は「大きな偏りなし」と表示する。
- [ ] 健康・メンタル運が65点以下の毎日・週・月・年は、通常の本文内で「体調・メンタルを気にかける日／期間」と短く表示する。占い点数を病気のなりやすさ・受診の必要性に結び付けず、病名の予測をしない。
- [ ] 毎日占いの上部で、選択中の1日分をAIチャット相談用JSONとして保存できる。
- [ ] プロフィールの「趣味・悩みなどを占いへ反映する」をオフにすると、切替が即時保存され、出生情報を残したまま趣味・悩み・文体が占い文から除外される。
- [ ] 旧版からの上書き更新後、旧AIモデル・途中ダウンロード・状態情報が削除され、プロフィールと占い設定が残る。
- [ ] 旧版からの上書き更新後、廃止した鑑定履歴・毎日の振り返りデータも削除され、保存プロフィール・出生情報・共有設定は残る。バックアップJSONに会話履歴や振り返りは含まれない。
- [ ] 毎日・週・月・年・カスタム鑑定にAIや生成モデルを示す文言、設定、ダウンロード導線がない。
- [ ] 公開ソースに、廃止済みの外部AI通信、ローカルモデルのダウンロード・実行、生成用プロンプトが残っていない。
- [ ] プロフィールのライセンス情報に、廃止したAIデータ・モデルの記述がない。
- [ ] Profile APKの要求権限に `INTERNET`、前景サービス権限が含まれない。
- [ ] 外部相談用JSONの画面・共有件名が「AIチャット相談用データ」と表示され、アプリ内でAIが動く機能ではないことが分かる。
- [ ] チャットで日付を指定して注意点を聞くと、その日付と異なる日の汎用文が繰り返されず、指定日の12:00 JSTの星配置を使った回答になる。
- [ ] スマホの鑑定ナビではテーマ・聞きたいこと・日付を選び、タブレットでは状況・知りたい結論・対象期間まで選んで、具体的な鑑定質問を作成し、そのまま送信できる。
- [ ] タブレットの鑑定ナビまたは自由入力から送信した後は、ナビが閉じて回答欄を広く表示する。
- [ ] タブレットでは会話途中も鑑定ナビが表示され、スマホと同じ短い結論中心の鑑定文になる。
- [ ] タブレットのカスタム鑑定では、重複する質問例チップが入力欄に隠れず、鑑定ナビ・チャット欄・入力欄が同時に見える。
- [ ] タブレットの初回チャット画面では、鑑定ナビの下に内容のない細い履歴欄が残らない。
- [ ] スマホの初回チャット画面では、鑑定ナビと重複する質問例チップが途中から表示されない。
- [ ] 鑑定ナビの本文が文字数上限で文の途中に切れず、短縮時も完結した文で終わる。
- [ ] 鑑定ナビに失敗した時、会話欄に失敗したことと再試行方法が表示される。
- [ ] 鑑定ナビの「比較する」は、今月・来月の片方だけでなく両方の日の点数を表示して結論を出す。
- [ ] 月間・年間占いで、外部相談用の構造化JSONを出力して保存先を選べる。
- [ ] 週・月・年占いの上部にAIチャット相談用JSONの案内があり、週・月では日ごとのデータを使って日付指定の相談ができると分かる。
- [ ] 月間・年間の鑑定JSONとバックアップJSONの作成時は、「出力中…」が作成開始前に一度表示され、作成完了後に共有先選択を開く。
- [ ] 月間JSONの各日には、JST日時付きのトランジット配置・月ボイド・逆行情報が入り、期間開始日の配置を日付なしの代表値として出力しない。
- [ ] 週・月・年JSONの`period_scores`には、点数の集計方法、説明用の代表日時、日別データとの差が明記され、「現在の配置」と混同しない。
- [ ] 週JSONの7日分、月JSONの全日分、毎日JSONの対象日は、すべて12:00 JSTのスコアとトランジット配置になっている。
- [ ] 毎日・週・月・年JSONの各基準時刻には、`lunar_phase`として8段階の月相・照度・月齢目安と、当日の新月／上弦／満月／下弦の`major_phase_event_jst`が入り、逆行天体に加えて空のステリウムとグランドトラインを示す`special_configurations_at_reference_time`が入る。
- [ ] 年間JSONには各月1日・15日12:00 JSTのトランジットと月別5運勢点数が入り、年間点数の24時点集計と照合できる。
- [ ] 毎日の振り返りと鑑定ログの画面・保存導線がなく、チャットの会話はアプリを閉じると残らない。
- [ ] 占い結果が医療、法律、投資などの重要判断を代替しないことを明記している。

## 共有

- [ ] テスト配布時は、対応ソースを`main`へ反映した後で`v`から始まる新しいタグをpushし、GitHub ActionsがGitHub Releasesのプレリリースへ`app-profile.apk`を自動添付したことを確認する。ソース確認用URLとAPKダウンロード用URLを別々に案内する。
- [ ] Netlify紹介ページでは、テスト版であること、APK配布ページ、公開ソースへの導線を確認する。

- [ ] 共有カードが壁紙＋文字のみで生成される。
- [ ] Android 8以降で、従来の猫と星空の四角い絵柄の四隅まで見え、外周が濃い紫のアダプティブアイコンが表示される。Android 7以前でも既存PNGアイコンが表示される。
- [ ] ボタン・アイコン・タップ可能カードは、押している間に明るい水色の押下表示が出る。
- [ ] 下部タブ／側面タブを続けて押しても、切替中は二重に画面を生成せず、アプリが落ちない。
- [ ] 同じ出生情報・ハウス方式で毎日、週、月、年を再表示した時、ネイタル配置を毎回再計算しない。一度開いた週月年・星の解説タブから戻っても状態を捨てず、週月年の切替時は押下後に「読み替え中…」が表示され、連打できない。
- [ ] 毎日占いの時間帯カードは、出生図・月ボイド探索を時間帯ごとに4回繰り返さず、同日の月ボイドと星座移動の探索結果を再利用して表示される。
- [ ] 毎日・週・月・年の折れ線グラフが、それぞれ7日・4週・12か月・5年を示し、各点が対応する占いカードの点数と一致する。
- [ ] 逆行開始・終了が日付境界付近も含めて星イベント、総合運の補足、JSONの`station_events_jst`へ同じ時刻で出力され、開始日以降の逆行期間中も「逆行中」と表示される。出生図・トランジットの星カードには該当星だけ「逆行」が表示され、展開本文には出生図＝内面で育てる読み、トランジット＝見直し・再調整の読みが出る。
- [ ] 星の解説の本格トランジット欄に「本日の主要配置」があり、逆行、空の主要アスペクト、ステリウム、グランドトライン・レア配置、月ボイドを該当時だけ短く表示する。配置が多い日は全アスペクト表と各星カードで続きが確認できる。
- [ ] 星の解説の本格ネイタル欄に「生まれ持った主要配置」があり、太陽・月、ASC/MC、出生時の逆行、星の集中、カイト・レア配置が短く表示される。詳細は各星カードで確認できる。
- [ ] 水星から冥王星までの逆行が、日別・週・月・年の同じスコア計算へ分野別の見直し補正として反映され、点数根拠にも「逆行中の星」として出る。
- [ ] グランドトライン、カイト、Tスクエア、グランドクロス、ヨッド、ブーメラン、ミスティックレクタングル（ダイヤモンド）、クレイドル（ゆりかご）、ハンマー・オブ・ソー、グランドセクスタイルが検出対象となり、トランジットは星イベント・JSON・点数根拠へ反映される。
- [ ] 鑑定ナビで「本日」「今日」など同義の表記が同じ意図として判定される。
- [ ] 鑑定ナビでテーマ・結論・期間を選んで会話形式の鑑定を開始でき、送信後もナビを開き直せる。
- [ ] TOKIMEKIを起動済みの状態でも、共有カードから投稿画面を開ける。
- [ ] 同じ状態で2回連続共有しても白画面にならず、PNGが添付される。
