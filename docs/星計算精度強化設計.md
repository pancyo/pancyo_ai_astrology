# 星計算精度強化設計

Android版はSwiss Ephemeris Free Edition/AGPLをネイティブ組み込みし、高精度星データを優先して使う。
Web/ネイティブライブラリ未読込時だけ、アプリ内の簡易天体計算へフォールバックする。
商用利用、改変、再配布条件を満たす範囲で、段階的に精度を上げる。

## 優先順位

1. 月の星座移動時刻
2. 月ボイド
3. ASC/MC
4. ハウス計算
5. アスペクト精度
6. リターン判定
7. 年月運の期間内推移

## 方針

- Swiss Ephemerisは、アプリ本体をAGPL互換でソース公開する前提で採用する。
- 配布前に公式ライセンス、著作権表記、エフェメリスファイル配布条件を確認する。
- 自前計算はWeb/ネイティブライブラリ未読込時/検証失敗時のフォールバックとして残す。
- 精度に限界がある箇所はアプリ内で注意書きを出す。

## 現在の仕様

- 出生地は主要地名または緯度経度入力。北海道の主要都市は市名・住所文字列から内部座標へ自動変換する。
- プロフィールでは北海道、東北、関東、中部、近畿、中国の主な都市を地域ごとに選べる。選択肢と同じ市名の手入力も同じ内部座標へ変換する。
- 未入力時は北海道札幌市を仮出生地にする。
- 未入力時の出生時間は12:00。
- Android版はSwiss EphemerisのPlacidusカスプを使い、Placidusを標準ハウス方式にする。
- プロフィール画面でWhole Signへ切り替え可能。選択した方式は端末内へ保存する。
- 星計算の入口は `EphemerisProvider` に切り出し済み。
- 現在の実装は `AstrologyDataSources.current` が `SwissEphemerisProvider` を優先し、未読込時だけ `SimpleEphemeris` に戻す。
- Swiss EphemerisはAndroid CMakeで `libpancyo_sweph.so` として組み込み、Dart FFIは条件付きimportにする。
- `SimpleEphemeris` は高精度アストロデータではなく、画面上でも簡易計算として表示する。
- Android版では星座、月、ハウス、ボイド、リターン、月年占いの根拠を高精度アストロデータ経由にする。

## 日付連動

毎日の占いの日付ナビゲーションは、指定日のトランジットを `AstrologyEngine.buildPreviewContext` に渡して算出する。

現時点で日付連動しているもの:

- 月ボイド表示
- 主要アスペクト表示
- リターン補正表示
- 総合運カードの点数と本文
- この日のヒント本文
- 各カードの現在の星座、サイン移動、ハウス通過、出生図ハウス
- 月年占いの点数、根拠、運勢グラフ

毎日の簡易総合運は、必ず点数ベースの総合評価から書き始める。
月ボイドは主文ではなく補足として扱い、「良い日か慎重な日か」が先に伝わる形にする。
点数は50から99点の範囲で、固定値ではなくアスペクト種別、オーブ、リターン、ハウス、月ボイド、出生図を補正して算出する。日付の数字だけを使う疑似的な補正は採用せず、対象日の実際の星配置によって変動させる。詳細は`点数計算方法.md`を正とする。

今後さらに連動させるもの:

- 月年占い本文の期間イベント差し込み強化
- 月年占いグラフの月相/ボイド厳密反映

## 改善案

### Swiss Ephemeris置き換え状態

1. 太陽、月、主要惑星の黄経: Android Swiss経由。
2. 月の星座移動時刻: Android Swiss経由。
3. 月ボイド: Android Swiss経由の月・惑星位置で判定。
4. ASC/MC: Android Swiss `swe_houses` 経由。
5. ハウス計算: Android版はPlacidusカスプを取得し、出生図・トランジット・ハウス集中へ同じ方式を適用する。
6. アスペクト、リターン、ステリウム判定: Swiss配置を元に既存ロジックで判定。
7. 月年占いの期間内イベント: `EphemerisProvider` 経由。

### EphemerisProvider境界

Swissとフォールバックを切り替える境界として、次の責務を `EphemerisProvider` に集約する。

- 出生地の解決
- 出生日時の解決
- 天体配置
- アスペクト
- ハウス通過
- ステリウム
- リターン
- 月ボイド
- 次サイン入り

アプリ側は `AstrologyDataSources.current` を通して星データへアクセスする。
占い画面や点数計算側のロジックからは、Swiss Ephemerisを直接呼ばず、この入口を通す。
星座境界付近の誤差を避けるため、リリース時に本格占星術を名乗る表示では `usesHighPrecisionAstroData` が true のデータソースを使う。

### 月ボイド

- 月のサイン区間をより細かく探索する。
- 月と主要天体の最後のメジャーアスペクトを判定する。
- ボイド開始、終了、次サイン入り時刻を表示する。

### ハウス

- Placidusを標準とし、出生時間と出生地がある時にSwiss Ephemerisのカスプを使う。
- Whole Signは比較・伝統方式として切替可能にする。
- Web/ネイティブライブラリ未読込時はWhole Signへ安全にフォールバックし、画面へ実際の方式を表示する。

### 年月運

- 月運は月初、月中、月末の3点を見る。
- 年運は月ごとの推移グラフに反映する。
- 星座移動とハウス移動を期間内イベントとして表示する。
