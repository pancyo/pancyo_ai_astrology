# 開発方針

## アプリ名

- 正式名称: ぱんちょ式 超本格占星術占い
- 短縮表示名: ぱんちょ式星占い
- 英語表記: pancyo Astrology
- Android applicationId: `com.pancyo.aiastrology`

## 基本方針

- 占いはアプリ内の占星術計算とルールベース文章だけで完結させ、外部サービスや生成モデルへデータを送らない。
- 利用者に見える画面、共有文、ライセンス情報、公開ソースには、現行機能でないAI・モデル・ダウンロードの表記や実装を残さない。
- Profile APKを含め、通常利用に不要なネットワーク・前景サービス権限は宣言しない。
- 毎日占いの上部には、JSTで時刻を明示した星イベントと、「深夜・朝・日中・夜」それぞれの星配置を反映した短い行動案内を表示する。星イベントは星座移動、月ボイド、個人天体の逆行、逆行開始・終了の留、新月・満月、当日に成立する空のステリウムとグランドトラインを、実際に検出できた場合だけ表示する。
- 毎日占いの上部には、選択中の1日分の出生図・天体配置・月ボイド・5運勢点数を含むAIチャット相談用JSONの保存導線を置く。
- 通常の毎日・週・月・年占いは、日付、出生図、アスペクト、リターン、ハウス、月ボイドを根拠に点数と本文を作る。
- 毎日占いでは、逆行開始・終了の留がある日に、星イベントだけで終わらせず、簡易・本格の総合運本文にも該当天体のテーマと「切替直後は見直してから動く」判断を反映する。月ボイドと重なっても省略しない。新月・満月、太陽・水星・金星・火星の星座移動、空のステリウムも該当日に本文へ反映する。
- 性格・趣味・悩み・読み方などの追加プロフィールは、利用者が反映のオン／オフを選べる。切替は即時保存し、オフ時は入力内容を保持したまま占い文から除外する。出生日時・出生地の星計算は常に使う。
- 鑑定ナビはルールベースで回答し、重要な判断を代替しない注意を常に守る。今週から今後5年まで、期間指定に応じて日別・月別の星配置と点数を計算する。
- 鑑定ナビの本文は文字数だけで途中切れにせず、短縮する場合も完結した文の終わりで止める。文末が上限内にない場合は全文を表示する。
- 鑑定ナビの作成に失敗した時は、通知だけで終えず、会話欄に「鑑定を作成できなかった」ことと再試行手順を表示する。
- チャットで`7/23`や`2026年7月23日`のように日付を指定して注意点・運勢を聞かれた場合は、その日の12:00 JSTの配置を再計算し、汎用の相談文を返さない。
- 鑑定ナビの初回画面では、スマホはテーマと聞きたいことを選び、タブレットはテーマ、いまの状況、知りたい結論、対象期間まで選択して具体的な質問を生成する。日付相談は日付ピッカーで指定し、「今月始める／来月始める」の比較は両方の日を計算して比較する。ナビまたは自由入力から鑑定を送った後は、回答を広く見せるためナビを閉じる。初期画面の重複する質問例チップは出さず、追加の質問例は電球ボタンから開く。端末サイズに関係なく短い結論中心の本文を返す。自由入力は補助として残す。
- 月間・年間占いでは、出生図、トランジット、点数根拠を構造化JSONとして出力し、利用者がChatGPTやGeminiなど外部AIチャットへ渡せるようにする。月間は日別、年間は各月1日・15日の日時付きトランジットと月別点数を出力し、期間開始日の配置を日付なしの代表値として扱わない。
- 週・月・年JSONの`period_scores`は、点数の集計方法と、説明用の配置が期間開始日12:00の代表値であることを別々に明示する。日別の相談には`daily_scores`、年間の月別相談には`annual_months`を使う。
- 毎日・週・月・年のJSON内のスコアとトランジット配置は、すべて対象日の12:00 JSTで計算する。週JSONも0:00ではなく12:00を使う。
- 毎日・週・月・年JSONは各基準時刻の逆行情報に加え、空のステリウムとグランドトラインを`special_configurations_at_reference_time`として構造化して出力する。
- 週占いの運勢グラフは、曜日だけでなく月/日も併記して対象日を取り違えないようにする。
- 週・月・年占いの上部にはAIチャット相談用JSONの案内を置く。週・月では日別データを含むことと日付を指定して相談できること、年間では月別データを含むことを明記する。
- 共有カードは「壁紙＋文字のみ」の方針を維持する。
- Android 8以降のランチャーはアダプティブアイコンを使い、従来の猫と星空の四角い絵柄の四隅まで見える大きさに収め、外周は星空になじむ濃い紫で表示する。Android 7以前は既存のPNGを使う。
- タップできるボタン、アイコン、カードは押している間に明るい水色の波紋・ハイライトを出す。タブ切替は切替直後の約0.16秒だけ他のタブを受け付けず、連続タップで画面生成が重ならないようにする。
- 出生図のハウス・ネイタル配置は、出生情報とハウス方式が同じ間は再計算せず共有キャッシュを使う。毎日占いは日別コンテキスト、週月年占いは日時コンテキストと期間カードをキャッシュし、日付・期間の再訪問を軽くする。一度開いたタブは画面状態を保つため、週月年・星の解説から戻ってもキャッシュを捨てない。週月年の切替は「読み替え中…」を1フレーム表示してから計算する。
- 月ボイドと星座移動の探索結果は同じ日・同じ基準時刻で共有し、毎日占いの時間帯カードは出生図全体を4回作り直さず、その時刻の月の位置と日全体の計算済み点数だけを使う。
- 毎日占いは選択日から7日間を日ごとに、週占いは4週間を週ごとに、月占いは同一年の12か月を月ごとに、年占いは選択年から5年間を年ごとに折れ線グラフで示す。グラフの各点は対応する占いカードと同じ集計済み点数を必ず使い、近似値を別計算しない。
- 逆行開始・終了（留）は水星から冥王星までを対象に、JSTの日付境界の前後も探索して検出する。開始日だけでなく逆行期間中は毎日の星イベント・総合運・JSONへ「逆行中」と表示する。出生図とトランジットの星カードには、該当する惑星だけ「逆行」バッジと、出生図は内面で育てる読み、トランジットは見直し・再調整の読みを本文にも表示する。
- 星の解説の本格トランジット欄には、個別の星カードの前に「本日の主要配置」を置き、逆行中の星、空の星同士のタイトなアスペクト、ステリウム、グランドトライン、その他のレア配置、月ボイドを短く一覧表示する。詳細は各カードと全アスペクト表へ誘導する。
- 星の解説の本格ネイタル欄には、個別の星カードの前に「生まれ持った主要配置」を置き、太陽・月、ASC/MC、出生時の逆行、星の集中、カイト・その他のレア配置を短く一覧表示する。出生図を自分だけの特別な配置として把握しやすくする。
- 逆行中の星は表示だけに留めず、日別・週・月・年の共通スコア計算へ穏やかな見直し補正として反映する。水星から冥王星まで分野ごとの補正を定め、同日の合計下限を設けて過大に点数を下げない。
- レア配置はグランドトライン、カイト、Tスクエア、グランドクロス、ヨッド、ブーメラン、ミスティックレクタングル（ダイヤモンド）、クレイドル（ゆりかご）、ハンマー・オブ・ソー、グランドセクスタイルを対象に、ネイタルとトランジットで検出する。トランジットは星イベント・JSON・点数根拠へ、ネイタルはJSON・点数根拠へ反映する。
- 鑑定ナビの質問判定は、日本語の同義語・言い換え辞書で正規化してから行う。「本日」は「今日」と同じ質問として扱う。
- 鑑定ナビは会話形式を残しつつ、テーマ・知りたい結論・対象期間を選んで質問文を作れる導線にする。送信後も利用者がナビを開き直せるようにする。

## 星データとライセンス

- Android版はSwiss Ephemeris Free Edition/AGPLを高精度星データとして組み込む。
- Swiss Ephemerisを使うため、アプリ本体はAGPL互換でソース公開する前提にする。
- 公開リポジトリにはアプリの対応ソース、`LICENSE`、`NOTICE.md`、第三者ライセンス資料を含める。一方で、端末の検証画像、UIダンプ、クラッシュログ、SDKパス、署名鍵は含めない。
- GitHubの既定ブランチへの反映を公開ソースの正とし、紹介サイトをNetlifyへ接続する場合は、そのブランチへの反映でサイトを自動更新する。APKの配布更新はこれと別に管理する。
- テスター向けAPKはGitHub Releasesでプレリリースとして配布し、ソース確認用のリポジトリURLとAPKダウンロード用URLを分けて案内する。
- Netlifyの紹介ページはリポジトリ直下の`site/`を公開対象とし、GitHubの`main`ブランチへのpushで自動更新する。
- 現在のAndroid組み込みはMoshier計算を使用し、追加エフェメリスファイルは後日の任意ダウンロード候補にする。
- 採用するデータとライブラリは、商用利用、改変、再配布、ライセンス表記の条件を確認し、`docs/ライセンス台帳.md` に記録する。

## 表示と保存

- 占い点数は50から99点の範囲に収め、100点満点の断定表示にしない。
- 毎日占いの総合運要約は、4運勢のうち80点以上をすべて「好調」、65点以下をすべて「注意」として表記する。該当がない側は「大きな偏りなし」とする。
- 健康・メンタル運が65点以下の毎日・週・月・年は、通常の健康・メンタル運本文の中で「体調・メンタルを気にかける日／期間」と短く伝える。根拠となる月、アスペクト、ハウス通過、月ボイドなどは通常の占い文で示す。病気のなりやすさ・受診の必要性としては扱わず、病名・発症の予測はしない。
- 星座名の表示ラベルは「牡羊座」のように「座」まで含む値を使うため、画面文で「座」を重ねて付けない。
- 毎日占いの基準時刻は選択日の12:00（JST）に統一し、JSON内の日時は計算時刻をUTC+09:00へ換算して記録する。
- 保存プロフィールは最大20人を端末内に保存する。鑑定の会話履歴と毎日の振り返りは保存しない。旧版に残る会話履歴・振り返りデータは、更新後の初回起動時にプロフィールや占い設定を残したまま削除し、バックアップ対象にも含めない。
- プロフィール、占い履歴、バックアップに不要な外部送信機能を追加しない。
- 月間・年間の鑑定JSONとプロフィールのバックアップJSONは、作成中に操作を受け付けない進捗表示を確実に描画してから作成し、完了後に共有先選択を開く。
- 旧版から上書き更新した場合は、旧生成モデル、途中ダウンロード、状態情報、廃止した会話履歴・毎日の振り返りだけを起動時に削除する。プロフィール・出生情報・占い設定は削除しない。

## 更新時のルール

- 占星術計算、表示、共有の仕様を変えた時は、この文書と`docs/リリース前チェックリスト.md`を更新する。
- `dart analyze` は実行しない。手動コード確認、`rg`、括弧数確認、Gradleビルド、実機確認で検証する。
