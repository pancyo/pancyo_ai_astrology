# ライセンス台帳

採用したライブラリ、星データ、素材を記録する台帳。

## 使用中ライブラリ

| 名称 | 用途 | 状態 |
| --- | --- | --- |
| pancyo Astrology | アプリ本体 | AGPL-3.0-or-later |
| Flutter | アプリ基盤 | 使用中 |
| shared_preferences | プロフィール設定の保存 | 使用中 |
| share_plus | 共有カード・JSON出力 | 使用中 |
| path_provider | 出力ファイルの一時保存 | 使用中 |
| url_launcher | 外部リンク起動 | 使用中 |

## 星データ

| 名称 | 用途 | ライセンス | 状態 |

## アプリ内表記

Android版の星計算にはSwiss Ephemeris Free Editionを使います。このアプリはAGPL条件に合わせ、ソース公開前提で整備しています。現在は追加エフェメリスファイルを同梱せず、Moshier計算で動作します。
