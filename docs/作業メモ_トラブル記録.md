## 2026-09-05 — AAB成果物のダウンロード

- **状況**: GitHub Actions #15 は成功したが、最初に押したダウンロードリンクでは一時ファイル（`.crdownload`）が止まった。
- **原因**: 成果物欄には同じ見た目のリンクが複数あり、表示テキストのないリンクを先に選んだ。
- **確認**: DownloadsフォルダでZIPが完成していること、展開後に `app-release.aab` が存在することを確認する。
- **再発防止**: 成果物名が表示されているリンクを選び、ZIPの完成と展開後のAABを必ず確認してから次工程へ進む。

## 2026-09-05 — GitHub Actionsのブランチ選択

- **状況**: ワークフロー実行画面の初期ブランチが `main` だった。
- **確認**: 実行前に対象コミットとブランチを表示欄で照合し、今回の `fix/v0.3.50-json-evidence-tab-color` と `c18bd7e` を選択した。
- **再発防止**: 実行後の画面でもコミットハッシュ、ブランチ、versionCodeを確認する。

## 2026-09-05 — Play ConsoleへのAAB再アップロード

- **状況**: 最初のアップロード処理を待たずに画面を再読み込みし、同じAABを再アップロードしたため「バージョン コード 81 はすでに使用されています」と表示された。
- **原因**: 最初のアップロードがバックグラウンドで完了していたことを、再試行前に最新のリリース／App Bundle一覧で確認しなかった。
- **確認**: Play Consoleの「ライブラリから追加」に `81 (0.3.55)` が登録済みであることを確認し、登録済みAABを下書きへ追加できた。
- **再発防止**: アップロード後は処理完了を待ち、再試行前にApp Bundle一覧とversionCodeを確認する。同じversionCodeは絶対に再利用しない。

## 2026-09-05 — Play Console操作再開時のブラウザ連携

- **状況**: 再開時にChrome連携が切れており、別のブラウザではデベロッパーアカウント作成画面へリダイレクトされた。
- **影響**: クローズドテストの更新操作はまだ実行していない。公開済みの内部テスト版には変更なし。
- **再発防止**: Play Console操作前に、正しいChromeのPlay Console画面が接続されていることを確認してから操作する。

## 2026-09-06 — クローズドテスト報告3件の反映

- **状況**: 鑑定ナビの期間表示、Android 14での下部切れ、プライバシーポリシー画面の右端はみ出しについて報告を受けた。
- **原因**: スマホ用の「良い時期」質問だけ期間を3か月に固定していた。鑑定ナビの選択チップは縦に長く、ナビ部分がスクロール対象外だった。ポリシー本文の`main`がcontent-boxのままで、狭い画面では内側の余白分だけ横にはみ出し得た。
- **確認**: 期間選択をモード別に整理し、スマホの質問プレビューにも選択期間を反映。小さい画面では鑑定ナビを縦スクロール可能にして入力欄を押し出さないようにした。ポリシーCSSは全要素をborder-box化し、長いURLも折り返すようにした。ウィジェットテストとAndroidデバッグAPKビルドが成功。
- **再発防止**: 期間の選択肢・生成質問・解析キーワードを同時に確認し、スマホ幅でナビ全体を開いた状態のレイアウトをテストする。外部ページは狭い幅で横スクロールが出ないことも確認する。

## 2026-09-06 — 内部テスト登録時のversionCode重複

- **状況**: 内部テストへ同じAABを登録しようとしたところ、「バージョンコード82はすでに使用されています」と表示された。
- **原因**: 同じ82（0.3.56）をクローズドテスト側へ先に保存していたため、Play Consoleでは別トラックへの重複登録ができなかった。
- **確認**: 内部テスト側のアップロード処理は完了したが、検証段階で拒否され、内部テストへの変更は未保存。既存の内部テスト0.3.55には影響なし。
- **再発防止**: 複数トラックへ同じ修正版を登録する場合も、トラック間でversionCodeを再利用しない。登録順と各トラックの下書きを確認してからAABを作成する。

## 2026-09-06 — プライバシーポリシーのモバイル横はみ出し再発

- **状況**: テスター端末でプライバシーポリシーの枠が右端からはみ出し、本文がずれて見えた。
- **原因**: Netlifyが接続している`main`には、`main`要素の`box-sizing`と最大幅を明示した修正版がまだ反映されていなかった。アプリ更新だけでは外部HTMLの表示は変わらない。
- **確認**: 公開ページの実測で`main`がcontent-box（余白分だけ横にはみ出す状態）になっていることを確認した。HTML側を明示的な`width:100%`・`max-width`・`box-sizing:border-box`へ修正し、アプリのリンクには更新識別子を付ける。
- **再発防止**: 外部ページ修正はアプリAABと別に`main`への反映・Netlify公開状態を確認し、実機幅で横スクロールがないことを確認する。AABを作る場合も、ページ側とアプリ側の両方を対象にする。

## 2026-09-07 — 共有カード編集画面のステータスバー重なり

- **状況**: 共有カード作成画面のタイトルがAndroidのステータス／通知バーの下に入り、上部が重なって見える端末があった。
- **原因**: `showModalBottomSheet`の既定値では上端の安全領域をルート側で避けないため、シート内の`SafeArea`だけでは端末によって上部余白を復元できなかった。
- **確認**: 共有カード用の`showModalBottomSheet`に`useSafeArea: true`を指定し、タイトルをステータスバー下へ配置するようにした。既存のシート内`SafeArea`とスクロールは維持する。
- **再発防止**: Androidのステータスバー／ナビゲーションバーが表示される実機幅で、共有カード画面の上端と下端を確認してからテスト版を更新する。
