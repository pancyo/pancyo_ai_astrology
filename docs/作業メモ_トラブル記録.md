## 2026-09-05 — AAB成果物のダウンロード

- **状況**: GitHub Actions #15 は成功したが、最初に押したダウンロードリンクでは一時ファイル（`.crdownload`）が止まった。
- **原因**: 成果物欄には同じ見た目のリンクが複数あり、表示テキストのないリンクを先に選んだ。
- **確認**: DownloadsフォルダでZIPが完成していること、展開後に `app-release.aab` が存在することを確認する。
- **再発防止**: 成果物名が表示されているリンクを選び、ZIPの完成と展開後のAABを必ず確認してから次工程へ進む。

- **再発防止**: 実行後の画面でもコミットハッシュ、ブランチ、versionCodeを確認する。

## 2026-09-05 — Play ConsoleへのAAB再アップロード

- **状況**: 最初のアップロード処理を待たずに画面を再読み込みし、同じAABを再アップロードしたため「バージョン コード 81 はすでに使用されています」と表示された。
- **原因**: 最初のアップロードがバックグラウンドで完了していたことを、再試行前に最新のリリース／App Bundle一覧で確認しなかった。
- **確認**: Play Consoleの「ライブラリから追加」に `81 (0.3.55)` が登録済みであることを確認し、登録済みAABを下書きへ追加できた。
- **再発防止**: アップロード後は処理完了を待ち、再試行前にApp Bundle一覧とversionCodeを確認する。同じversionCodeは絶対に再利用しない。
