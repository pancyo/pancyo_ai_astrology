# ソース公開準備

Swiss Ephemeris Free Edition/AGPLを採用できるように、アプリ本体を公開できる状態へ整えるためのチェックメモ。

## 公開方針

- 高精度星データとしてSwiss Ephemeris Free Editionを使うため、アプリ本体をAGPL互換でソース公開する。
- 公開前に、秘密情報、個人情報、不要な生成物、ライセンス不明素材が混ざっていないか確認する。
- Google Play等で配布するAPKと、対応するソースコードの対応関係を説明できるようにする。
- アプリ内ライセンス画面、README、NOTICEから、Swiss Ephemeris公式情報とAGPL条件へ辿れるようにする。

## 公開前チェック

- [ ] APIキー、アクセストークン、署名鍵、keystore、パスワードが含まれていない。
- [ ] `build/`、`.dart_tool/`、端末固有ファイル、IDEキャッシュが含まれていない。
- [ ] 画像素材 `assets/images/astro_lake_hero.png` と `assets/images/pancyo_profile.png` の作成元、権利、利用条件を記録している。
- [ ] 使用中Flutter/Dartパッケージのライセンスを `docs/ライセンス台帳.md` に記録している。
- [x] AGPLを採用するため、`LICENSE`、README、アプリ内ライセンス画面に表記を追加している。
- [x] Swiss Ephemerisの公式著作権表記、AGPL条件、エフェメリスファイル配布条件を `NOTICE.md` と台帳に記録している。
- [x] 公開リポジトリURLをREADMEとアプリ内ライセンス画面に追加している（https://github.com/pancyo/pancyo_ai_astrology）。
- [x] 寄付は機能解放と結びつけず、任意寄付として表記している。

## 初回確認メモ

- 2026/07/10時点の簡易検索では、外部サービス用のAPIキー、署名鍵ファイル、keystore系ファイルは見つからなかった。
- `password`、`secret`、`token` 等の語は、説明文や `max_output_tokens` など無害な用途のみ確認。
- 2026/07/27に、`.gitignore`へ検証用画像・UIダンプ・クラッシュログ・端末別設定・署名鍵の除外を追加し、iOS/Web/NOTICE/帳票スクリプトの旧名称を現名称へ更新した。旧版の生成・通信コードと生成用プロンプトも削除した。
- 2026/07/27に、公開リポジトリにはMoshier計算に不要なSwiss Ephemerisの追加エフェメリスデータ、上流の実行バイナリ、テスト用データを含めない方針にした。Androidビルドで使うCソースとライセンス文書は同梱する。
- 公開直前には、もう一度同じ観点で確認する。

## 公開後に必要なこと

- リリースごとに、APKに対応するソースコードのタグを作る。
- 採用ライブラリやモデルを更新したら、ライセンス台帳とアプリ内表記を更新する。
- Swiss Ephemerisを導入した場合、利用者がソースへ辿れる導線をアプリ内にも置く。
