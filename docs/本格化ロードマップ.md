# 本格化ロードマップ

ソース公開とSwiss Ephemerisを前提に、占星術アプリとして本格化するための実装順を管理する。

## 目的

- 高精度な星データを使える形にする。
- ライセンス、配布、削除、チェックサム、ソース公開を先に整理する。
- 占いとチャット鑑定は、端末内の占星術計算とルールベース文章だけで成立する状態を維持する。

## フェーズ1: 公開準備

1. アプリ表示から内部ビルド番号を消し、表示バージョンだけにする。
2. `docs/ソース公開準備.md` に沿って、秘密情報、APIキー、個人情報、不要なビルド成果物が混ざっていないか確認する。
3. AGPL採用時のライセンス表記、ソース提供方法、README表記を整える。
4. `docs/ライセンス台帳.md` をアプリ内ライセンス画面へ反映できる形にする。

## フェーズ2: Swiss Ephemeris最小検証

1. 公式ライセンス、AGPL本文、著作権表記、エフェメリスファイルの配布条件を再確認する。
2. `EphemerisProvider` を実装するSwiss用データソースの最小版を作る。完了。
3. AndroidでSwiss Ephemerisを呼び出す最小構成を作る。完了。
4. 太陽、月、主要惑星、ASC/MC、月ボイド、次サイン入りをSwiss経由にする。完了。
5. 実機で太陽星座、月、ASC/MC、ボイド、点数変動を確認する。
6. 既存の自前簡易計算は、Web/ネイティブ未読込時のフォールバックとして残す。

## フェーズ3: ルールベース鑑定の改善

1. 出生図・トランジット・ハウス・アスペクトを根拠に、相談テーマ別の文章ルールを改善する。
2. チャット鑑定は、質問の種類ごとに結論、理由、具体的な一手を短く返す。
3. 低性能端末でも待ち時間を増やさず、同じ入力なら同じ根拠と結論を返す。
4. 実機で、日付指定・比較相談・長期間相談の文章と操作感を確認する。

## 完了条件

- アプリ表示は `v0.1.0` のような表示バージョンのみ。
- Swiss Ephemerisを使う場合、AGPLまたはProfessional Licenseの条件を満たしている。
- 寄付は機能解放と結びつかず、寄付なしでも全基本機能が使える。
