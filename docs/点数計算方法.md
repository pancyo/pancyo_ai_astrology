# ぱんちょ式星占い 点数計算方法

最終更新: 2026-07-16  
対象: 毎日占い、週・月・年占いの通常点数

## 1. この点数が表すもの

このアプリの点数は、出生図と対象時点の天体配置を重ねて作る**その分野の使いやすさの目安**である。出来事の発生や病気、交際成立、収入額を断定する数値ではない。

| 項目 | 設計 |
|---|---|
| 表示範囲 | 50〜99点。100点満点の断定にしない。 |
| 基準点 | 恋愛70、仕事74、金運68、健康・メンタル72。 |
| 総合運 | 毎日・週・月は、恋愛・仕事・金運・健康・メンタルの4点を平均して四捨五入する。年だけは、年間リターンの節目を別途反映する。詳細は「3-8」を参照。 |
| 最終処理 | `基準点 + 実際に該当した加減点 = 計算値`。計算値を四捨五入し、50〜99へ収めて表示する。 |
| 本格表示 | 「この点数の理由」から、該当した全加減点、小数1桁の値、オーブ、位相、計算式を確認できる。 |
| 簡易表示 | 専門用語を並べず、最終点と日常語の鑑定文を表示する。 |

例: 恋愛運なら `基準70点 + 4.6 + 2.0 + 2.2 - 2.1 = 計算値76.8点`、最終表示は`77点`となる。

## 2. 日付変動の目的と採用理由

### 目的

同じ出生図でも、毎日まったく同じ文章・点数にならないようにするためではなく、**対象日の月・惑星・アスペクト・ハウスの実際の変化を、出生図に照らして反映する**ことが目的である。

### 採用していない方式

| 採用しないもの | 理由 |
|---|---|
| 曜日、日付の数字、乱数だけによる加点・減点 | 星の配置と結び付かず、点数の根拠を説明できない。 |
| 「毎日変化させるため」の疑似的な日付波 | 同じ天体配置でも日付だけで意味が変わり、占いの根拠と画面表示が一致しなくなる。 |
| 根拠を持たない本文用の独自点数 | 再現性がなく、本文と点数の整合を検証できない。 |

### 採用する計算方法

| 日付変動の材料 | 何を比べるか | 変わる理由 |
|---|---|---|
| 出生図とのアスペクト | 当日の天体と出生天体の角度 | 月は約2〜3日、内惑星は日々位置を変えるため。 |
| 月のサイン | 当日の月と出生時の月のサイン関係 | 感情・体調・反応のリズムを日単位で反映するため。 |
| 月の通過ハウス | 月が出生図のどのハウスを通るか | 恋愛、仕事、金銭、休息など、その日に意識が向く領域を分けるため。 |
| 他天体の通過ハウス | 金星、火星、木星などが出生ハウスを通る位置 | 数日〜数か月続くテーマを日ごとの配置として反映するため。 |
| リターン | 当日の天体が出生時の同じ天体位置へ近づくか | 出生図のテーマが強く再起動する節目を反映するため。 |
| 空の天体同士のアスペクト | 例: 金星と木星、金星と火星 | その日の社会的・対人的な空気の組み合わせを加えるため。 |
| グランドトライン、出生図の集中 | その日に成立する図形、出生図のステリウムやカイト | 本人が反応しやすい持続的な特徴を反映するため。 |
| 月ボイド | 対象日の中で月ボイドが占める時間 | 新規決定より確認・調整を優先したい時間帯を、終日ではなく割合で反映するため。 |

### 基準時刻と再現性

| 画面 | 計算時刻・集計 | 採用理由 |
|---|---|---|
| 毎日占い | 選択日の12:00 JST | 朝・夜に開いても同じ日の点数と本文が変わらない。 |
| 週占い | 月曜〜日曜の各日12:00 JSTを計算し、7日平均と日別の強弱を表示 | 一週間の一点だけで決めず、動く日・慎重な日を示す。 |
| 月占い | 1日・8日・15日・22日・月末の各12:00 JSTを計算し、5点平均 | 月初だけの配置へ偏らず、前半・後半の流れを比較できる。 |
| 年占い | 各月1日・15日の12:00 JST、計24点を集計し、年間リターン補正を加える | 月初だけで一年を決めず、持続的な流れと年単位の大きな節目を両方拾う。 |

日付を同じにし、プロフィールも同じなら、同じ天体データから同じ点数が再計算される。本文も同じ根拠を使う。

## 3. 毎日占いの加減点一覧

複数の条件が同日に重なれば、それぞれを合算する。ただし、各項目には下表の件数・上限がある。

### 3-1. 出生図とのアスペクト

各運勢では、その分野に分類された強いアスペクトを最大3件使う。オーブは0〜6度を対象とし、正確な角度に近いほど係数が大きくなる。

`加減点 = アスペクト基礎点 × (0.45 + ((6 - オーブ) / 6) × 0.75)`

| アスペクト | 基礎点 | オーブ6度付近 | オーブ0度（正確） | 採用理由 |
|---|---:|---:|---:|---|
| コンジャンクション | `+4.0` | `+1.8` | `+4.8` | 二つの天体の意味が重なり、強く出る。 |
| セクスタイル | `+3.5` | `+1.6` | `+4.2` | 意識して使うと機会へつなげやすい。 |
| トライン | `+6.0` | `+2.7` | `+7.2` | 無理なく流れを使いやすい。 |
| スクエア | `-5.0` | `-2.3` | `-6.0` | 葛藤・負荷・調整課題が出やすい。 |
| オポジション | `-2.5` | `-1.1` | `-3.0` | 対人関係や内外の綱引きが起きやすい。 |

分野の分類は、金星を含むアスペクトを恋愛、木星を含むものを金運、水星・土星を含むものを仕事、月を含むものを健康・メンタルへ優先して割り当てる。それ以外は総合の材料となる。

### 3-2. 月のサインと出生時の月

これは**出生時の太陽星座ではなく、出生時の月星座**との関係で決まる。同じサインにいるだけで出生時の太陽へ自動加点する仕組みではない。月と出生時の太陽が6度以内でアスペクトを作る場合は、上のアスペクト計算として別途反映する。

| 当日の月と出生時の月のサイン関係 | メンタル | 総合換算 | 恋愛・仕事・金運換算 | 採用理由 |
|---|---:|---:|---:|---|
| 同じサイン（0度相当） | `+4` | `+2` | `+1` | 感情の扱い方と当日のリズムが重なりやすい。 |
| 隣（30度相当） | `+1` | `+1` | `0` | 小さな刺激はあるが、強い追い風ではない。 |
| 60度相当 | `+3` | `+2` | `+1` | 気分を使いやすく、調整しやすい。 |
| 90度相当 | `-3` | `-2` | `-1` | 感情の引っかかりや焦りが出やすい。 |
| 120度相当 | `+3` | `+2` | `+1` | 心の流れが自然につながりやすい。 |
| 150度相当 | `-1` | `-1` | `0` | 予定や気分の微調整が必要になりやすい。 |
| 180度相当 | `-4` | `-2` | `-1` | 気分の振れ幅が大きくなりやすい。 |

太陽またはASCが天秤座・牡牛座の人は、支配星である金星が当日に強く関わる時、下の「金星支配の感受性」も追加される。太陽天秤座であることは、月天秤座の直接加点ではなく、この金星感受性へ関係する。

### 3-3. 天体の通過ハウス

当日の通過天体は各分野で最大2天体を合算し、合計を四捨五入した上で`-4〜+5`に制限する。

| 分野 | 加点される出生ハウス | 減点される出生ハウス | 採用理由 |
|---|---|---|---|
| 恋愛 | 第5 `+3.5`、第7 `+4.0`、第8 `+2.0` | 第12 `-2.0` | 恋愛、関係性、親密さのテーマを優先する。 |
| 仕事 | 第6 `+3.5`、第10 `+4.5`、第11 `+2.5` | 第12 `-2.0` | 実務、社会的立場、仲間との活動を優先する。 |
| 金運 | 第2 `+4.0`、第8 `+3.5`、第11 `+2.5` | 第12 `-2.0` | 収入、共有資源、成果・人脈を優先する。 |
| 健康・メンタル | 第4 `+3.5`、第6 `+2.0`、第12 `+3.5` | 第8 `-2.0` | 生活基盤、健康管理、休養・内面を優先する。 |
| 総合 | 第1 `+2.5`、第5 `+2.0`、第9 `+3.0`、第10 `+3.0` | なし | 自己表現、展開、学び、社会的活動を総合テーマとして扱う。 |

月だけのハウス通過には、日ごとの気分・活動量を強く拾うため、次の別補正を追加する。

| 月が通る出生ハウス | 反映先 | 点 | 採用理由 |
|---|---|---:|---|
| 第5・第7 | 恋愛 | `+2.0` | 楽しみ、恋愛、関係性へ気持ちが向きやすい。 |
| 第6・第10 | 仕事 | `+2.0` | 作業、責任、見せ方を進めやすい。 |
| 第2・第8 | 金運 | `+2.0` | お金、価値、共有資源の見直しに向く。 |
| 第4・第6・第12 | 健康・メンタル | `+3.0` | 生活、整え直し、休息への意識が高まる。 |
| 第8 | 健康・メンタル | `-1.0` | 心身の負荷を抱え込みやすい。 |
| 第1・第4・第10 | 総合 | `+1.5` | 自分自身、土台、社会的行動が動きやすい。 |
| 第12 | 恋愛・仕事 | `-1.0` | 表に出すより準備・休息を優先しやすい。 |

### 3-4. リターン

リターンは、当日の天体が出生時の同じ天体の位置へ近づく現象である。各分野では最大1件を使う。

`加減点 = (天体基礎点 + ハウス加点) × オーブ係数 × 位相係数 × 出生図感受性`

| 要素 | 値・式 | 採用理由 |
|---|---|---|
| 木星の基礎点 | `+8.0` | 成長、拡大、機会の周期として重視する。 |
| 土星の基礎点 | 仕事`+5.0`、金運`+1.5`、総合`+2.0`、恋愛`-2.0`、健康・メンタル`-1.0` | 責任・継続には追い風だが、負荷や慎重さも伴うため。 |
| 太陽・月の基礎点 | `+3.0` | 自己認識や日常感覚の節目として扱う。 |
| その他の天体 | `+2.5` | テーマの再起動として控えめに反映する。 |
| ハウス加点 | 木星の第1・5・9 `+3.0`、金運の第2・8 `+3.0`、恋愛の第7 `+2.5`、仕事の第6・10 `+2.5`、健康・メンタルの第4・6・12 `+2.0` | 分野と出生ハウスのテーマが一致する場合を強める。 |
| オーブ係数 | `0.45 + ((判定幅 - オーブ) / 判定幅) × 0.55` | 正確なリターンほど強くする。 |
| 位相係数 | 接近中`0.90`、ピーク`1.20`、余韻: 木星・土星`0.72`、その他`0.52` | 近づく時と正確時刻を重くし、遅い天体は余韻も残す。 |
| 出生図感受性 | `0.85〜1.38` | その天体が出生図の重要ハウス、分野ハウス、ステリウムにある人ほど反応を少し強める。 |

### 3-5. 空の天体同士のアスペクト

当日の空で起きる強い組み合わせを最大5件計算し、合計を`-5.0〜+7.0`に制限する。

`加減点 = アスペクト値 × オーブ係数 × 位相係数 × 分野係数 × ハウス係数 × 出生図係数 × 感受性`

| 組み合わせ | 主な分野係数 | 採用理由 |
|---|---|---|
| 木星×金星 | 恋愛・金運`1.00`、総合`0.70`、他`0.25` | 好意・魅力と拡大・機会の組み合わせ。 |
| 金星×火星 | 恋愛`1.00`、総合`0.55`、他`0.15` | 対人の熱量、誘い、行動性を反映する。 |
| 木星×水星 | 仕事・金運`0.90`、総合`0.55`、他`0.15` | 発信、交渉、学び、数字の広がりを反映する。 |
| 太陽×木星 | 総合`0.85`、金運`0.55`、他`0.20` | 自己展開と拡大を総合寄りに扱う。 |
| 金星×水星 | 恋愛・仕事`0.70`、他`0.20` | 会話、告知、誘い、表現を反映する。 |
| 木星×土星 | 仕事・金運`0.65`、他`0.30` | 拡大と現実的な構築を両立するテーマ。 |

この式のアスペクト値は、合`+5.4`、トライン`+4.6`、セクスタイル`+3.2`、スクエア`-3.4`、オポジション`-1.8`。位相は接近中`0.92`、ピーク`1.18`、余韻`0.62`とする。対象分野のハウスへある場合はハウス係数`1.22`、第12ハウスが中心なら一部の分野で`0.78`となる。出生図で木星と金星が合の人は、木星×金星の当日アスペクトをさらに`1.18`倍する。

### 3-6. 出生図の特徴と図形

| 条件 | 加点 | 採用理由 |
|---|---:|---|
| 金星支配の感受性 | 太陽またはASCが牡牛座・天秤座で、金星が当日にアスペクト・リターン・空のアスペクトとして活動: 恋愛`+2.2`、金運`+1.7` | 金星を支配星にもつ人は、金星が強い日に恋愛・価値・お金のテーマを少し強める。 |
| 当日のグランドトライン | 恋愛・金運: 金星または木星を含むと各`+4.0`、メンタル: 月を含むと`+3.0`、仕事: 水星または土星を含むと`+3.0`、総合は`+3.0`。合計上限`+6.0` | 調和的な三角形が分野に対応する天体を含む場合だけ反映する。 |
| 出生図ステリウム | 分野ごとに`+2.0〜+3.2`を基本とし、対応ハウスなら`1.18`倍。木星と金星を両方含む場合は恋愛・金運`+1.8`を追加。合計上限`+8.0` | 出生図で集中したテーマは、当日の天体に反応しやすい土台になるため。 |
| 出生図カイト | 総合`+3.0`、各分野`+2.0` | トラインだけでなく、オポジションと両端へのセクスタイルまで揃う配置を、活用可能な持続力として扱う。 |

### 3-7. 月ボイドと逆行

| 条件 | 計算 | 採用理由 |
|---|---|---|
| 月ボイド | `-(分野別基本減点 × 対象日に占めるボイド時間の割合)`。健康・メンタル`-4.0`、恋愛`-3.0`、仕事・金運`-2.0`、総合`-2.5` | 一日中ボイドとして減点せず、実際に重なる時間だけを反映する。新規決定より確認・調整へ向けるため。 |
| 逆行 | **現時点では独立した点数加減なし**。本格本文と全アスペクト表の注意材料として表示する。 | 逆行だけで一律に悪い点を付けると過度に単純化するため。逆行中でも、実際のアスペクト・ハウス・リターンで点数は変動する。 |

### 3-8. 年占いだけの年間リターン補正

年占いの各分野は、24時点での通常点数を平均した後、年内で最も強い追い風と最も注意したいリターンを確認し、その合計を`0.72`倍して追加する。年単位のリターンが、月ごとの平均に埋もれないようにするためである。

| 年間リターンの天体基礎点 | 値 | 採用理由 |
|---|---:|---|
| 木星 | `+8.0` | 年間を通す成長・拡大の節目として最重要視する。 |
| 金星 | `+5.5` | 恋愛、価値観、金銭感覚の節目として反映する。 |
| 水星 | `+4.5` | 仕事、学び、連絡、契約のテーマとして反映する。 |
| 月 | `+3.0` | 生活と感情の節目として反映する。 |
| その他 | `+3.5` | 長期テーマの切り替わりとして控えめに反映する。 |
| 土星 | 仕事`+5.0`、金運`+1.5`、総合`+2.0`、恋愛`-2.0`、健康・メンタル`-1.0` | 責任・継続には追い風だが、負荷と慎重さも伴うため。 |

年間リターンのハウス加点は、総合の第1・5・9・10ハウス`+3.5`、恋愛の第5・7・8ハウス`+3.0`、仕事の第6・10・11ハウス`+3.0`、金運の第2・8・11ハウス`+3.5`、健康・メンタルの第4・6・12ハウス`+2.5`を基本とする。接近中`0.82`、ピーク`1.18`、余韻は木星`0.72`・その他`0.55`の位相係数とオーブ係数を掛ける。

年の総合運は、4分野の年点数を平均したうえで、木星リターンが年内にあれば少なくとも`+8.0`、土星リターンがあれば`+2`を追加して50〜99点へ制限する。これは毎日・週・月にはない年単位の明示的な例外である。

## 4. 点数表示と本文の関係

| 段階 | 処理 | 採用理由 |
|---|---|---|
| 1 | アプリ側で星位置、アスペクト、ハウス、リターン、月ボイドを計算する。 | 事実となる天文・占星術データを端末内で再現可能に計算する。 |
| 2 | 分野別の基準点へ、該当した加減点を小数で加算する。 | 「なぜこの点数か」を追跡できる。 |
| 3 | 本格画面は基準点・全加減点・計算値・最終点を表示する。 | 占い師や検証用途で再確認できる。 |
| 4 | 本文ルールは点数だけでなく主要因、オーブ、位相、通過テーマ、月ボイドを参照する。 | 点数は高いのに本文が慎重、または逆の矛盾を防ぐ。 |
| 5 | 本文は日常語へ置き換える。 | 初心者にトラインやオーブを必須知識にしない。 |

## 5. 注意事項

- 同じサインに天体があるだけでは必ず加点しない。出生時の天体との角度、ハウス、オーブ、分野の関係を確認する。
- 出生時刻・出生地が未入力の場合、ハウスとASCを使う補正の精度は下がる。入力すると通過ハウスと感受性を本人向けに計算できる。
- 月・内惑星は動きが速く、日ごとの差が出やすい。木星・土星などはゆっくり動くため、リターンやハウス通過が一定期間続く。
- 点数は行動の優先順位を決める補助であり、医療、投資、契約、人生上の重要決定を単独で判断する根拠にはしない。
