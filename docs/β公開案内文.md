- ダウンロードと参加案内: https://pancyo-astrology.netlify.app

## β版について

- これは正式版前のテスト版です。
- Android端末向けです。初回インストール時は、端末側で提供元不明アプリの確認画面が出る場合があります。
- 不具合や気になる点があれば、**スクリーンショット・発生した日付・端末名**を添えて教えてください。
